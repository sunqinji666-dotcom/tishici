## 这是什么

tishici 是一个小型、自托管的个人灵感档案。提示词模式把生成模型、标题、提示词和最多 12 个图片/视频素材放进同一张卡片；随手记模式则提供独立的左右工作台，用来快速记下一句话、待办或带媒体的灵感。

页面默认使用夜间摄影工作台风格，并始终优先打开提示词。右侧初始渲染 6 条，向下滚动时按批懒加载，支持搜索、排序、复制、删除和当前页内的半透明媒体预览。

## 为什么值得用

- **打开即读**：访客不需要账号即可查看、搜索、复制和打开已发布内容。
- **发布有门槛**：发布与删除需要同一个运行时密码，验证后保存在当前会话。
- **草稿在本机**：开始打字或选择素材后，文字和媒体草稿自动保存到 IndexedDB；发布完成即删除草稿。
- **随手记独立保存**：提示词与随手记拥有各自的本机草稿和列表，切换时互不覆盖。
- **浏览器负责压缩**：不超过 1 MiB 的文件保持原样；超过后由浏览器转换，服务器只做大小与类型校验。
- **图片视频可以混放**：两组生成模型选择器独立存在，但两种提示词和随手记都能一次选择或拖入多张图片与视频。
- **适合快速回看**：多个素材以三层底片方式叠放；点开后可用左右按钮、方向键和底部缩略带切换。右侧先显示 6 条，继续滚动再自动载入。

## 一分钟上手

需要 PHP 8.1 或更高版本。

```bash
git clone https://github.com/sunqinji666-dotcom/tishici.git
cd tishici
cp .env.example .env
```

编辑本机 `.env`，设置一份只用于发布与删除的密码。不要提交真实 `.env`。

```bash
set -a
. ./.env
set +a
php -S 127.0.0.1:8080 -t site
```

然后访问 `http://127.0.0.1:8080/`。

生产环境请只把 `site/` 作为站点根目录，并在 PHP-FPM 运行环境中设置 `TISHICI_PUBLISH_PASSWORD`。同时确保 PHP 对 `site/uploads/` 和仓库同级的 `tishici-storage/` 具有写权限。`ops/tishici-cache-control.conf` 提供了可选的 nginx 首页无缓存规则。

## 工作方式

```text
输入提示词或随手记 / 拖入媒体
          ↓
浏览器自动保存本机草稿
          ↓
文件 ≤ 1 MiB ───────────────┐
文件 > 1 MiB → 浏览器本地压缩 ├→ 密码验证 → 发布卡片
                              │
服务器只校验大小与类型 ────────┘
          ↓
发布成功后清除本机草稿
```

图片会转换为 WebP。视频会转换为不超过 1 MiB 的 WebM 视觉预览，并校验输出可播放且时长完整；为优先保留画面和完整时长，压缩预览不保留音轨。

## 功能与边界

| 能力 | 行为 |
|---|---|
| 图片输入 | JPG、PNG、WebP |
| 视频输入 | MP4、WebM、MOV |
| 单条素材 | 最多 12 个，图片与视频可混合 |
| 压缩阈值 | 严格大于 1 MiB 时才在浏览器启动 |
| 服务器限制 | 上传结果不得超过 1 MiB；不做重编码 |
| 草稿 | IndexedDB，localStorage 作为文字回退 |
| 工作台 | 默认提示词；手动切换到独立随手记 |
| 列表 | 搜索、正倒序、初始 6 条并滚动懒加载 |
| 访问控制 | 公开读取；密码控制发布和删除 |
| 数据存储 | JSON 索引位于 `tishici-storage/`，媒体位于 `site/uploads/` |

这是一道适合个人站点的轻量共享密码门槛，不是多用户账号系统。它没有角色、找回密码、审计日志或速率限制。若站点内容不应被公开，请在反向代理层增加更完整的访问控制。

## 隐私与安全

- 仓库不包含真实发布密码；应用只读取 `TISHICI_PUBLISH_PASSWORD`。
- `.env`、运行时 JSON、用户上传、草稿与发布构建产物均被 Git 忽略。
- 图片和视频压缩发生在浏览器，服务器不会为媒体转码。
- 草稿不会主动同步到服务器；发布成功后，当前草稿会从浏览器存储中删除。
- 已发布内容对能访问站点的人公开，请不要发布秘密、客户隐私或不可公开的素材。
- 这套实现不声称提供端到端加密或完整身份系统。

## 常见问题

### 为什么没有完整账号系统？

它定位为个人提示词备份台。公开读取、密码发布的边界足够轻，但不适合多人协作或敏感内容。

### 为什么视频会变成 WebM？

超过 1 MiB 后，现代 Chromium 浏览器可以在本地把视频重新录制成轻量 WebM 预览。应用优先保留可播放性和完整时长，画质会根据视频长度下降。

### 没有许可证意味着什么？

当前仓库没有附带开源许可证，因此没有额外授予复制、修改或再分发权限。许可证由项目所有者后续决定。
